About This Tool

MeroDoseCalc – Meropenem Renal Function Reference Tool

MeroDoseCalc is an educational reference application developed to help healthcare learners and professionals understand how renal function can influence meropenem dosing in adults and pediatric patients.

The tool allows users to explore weight-based, age-specific, and renal function–related examples of dose adjustment, including scenarios such as dialysis and augmented renal clearance (ARC). It is intended for educational and informational purposes only and does not provide patient-specific treatment recommendations or medical advice.

Features

  • Demonstrates meropenem dose adjustment principles using user-entered data
  • Supports pediatric (Schwartz equation) and adult (Cockcroft–Gault) renal function estimation
  • Shows how Adjusted Body Weight (AdjBW) is used in obesity for learning purposes
  • Includes reference information for CRRT, ARC, and common dialysis modalities
  • Presents examples consistent with current published guidelines and literature for educational context

Equations Used

  • Pediatric (Schwartz equation): 0.413 × (Height in cm / Serum creatinine in mg/dL)
  • Adult (Cockcroft–Gault formula): ((140 – age in years) × weight in kg × gender factor) ÷ (72 × Serum creatinine in mg/dL)
    Gender factor: 1 for male, 0.85 for female
  • Adjusted Body Weight (AdjBW): IBW + 0.4 × (Actual body weight – IBW)
    IBW for male: 50 + 2.3 × (height in inches – 60)
    IBW for female: 45.5 + 2.3 × (height in inches – 60)
